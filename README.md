Mail Organizer DevOps Pipeline Project



A simple mail categorization app used as a demo project to showcase a full DevOps CI/CD pipeline using Git, GitHub, Jenkins, and Docker.



What it does:

Sorts sample emails into categories such as Work, Finance, Personal, Spam, and General using keyword matching.



DevOps Tools Used:

Git and GitHub for version control and remote repository

Jenkins for CI/CD pipeline automation

Docker for containerization and image build
